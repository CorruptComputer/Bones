This project has one overarching goal, to be the project that can manage any project.

Initial implementation is focusing on 3 main features:
- [[Asset Management]]
- [[Work Item Management]]
- [[Account Management]]


Under the hood Assets and Work Items are the same, the only difference is in our presentation to the user.

In this documentation if you find a section of something in a `code block` where the comments seem to be at the end of the commands it is asking you to follow, that means please read each command AND the comment before running any of them.
